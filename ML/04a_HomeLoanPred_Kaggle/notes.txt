Ordinal Categorical: The data description is key here. Many features are described with quality ratings:
ExterQual, ExterCond (Exterior quality/condition)
BsmtQual, BsmtCond, BsmtExposure, BsmtFinType1, BsmtFinType2 (Basement features)
HeatingQC (Heating quality and condition)
KitchenQual (Kitchen quality)
FireplaceQu (Fireplace quality)
GarageQual, GarageCond (Garage quality/condition)
PoolQC (Pool quality)
Nominal Categorical: MSZoning, Street, LotShape, LandContour, Neighborhood, BldgType, HouseStyle, RoofStyle, Foundation, etc.. These have no inherent order. 
The most efficient way to classify is to use the df.dtypes method in pandas to initially separate object (potential categorical) and numeric types, then use the provided Kaggle data dictionary to manually sort the object columns into nominal and ordinal categories.
